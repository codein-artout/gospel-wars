# Mockups

- `html/`: static, self-contained pages. Open any one in a browser; they link to each other. **These are the visual reference.** Fonts load from Google Fonts.
- `png/`: reference screenshots of `html/` at 1440, 1024 and 390 wide (desktop pages), 390 (phone pages) and 1200×630 (card). Compare your Playwright screenshots against these.
- `source/`: the original design-canvas files (`*.dc.html`) and `canvas.json`. Each has a `renderVals()` script with the sample data and, in `Main.dc.html`, the rose-window geometry and a working "Advance tick" demo. Read these for exact numbers and data; don't ship them.

Sample data in the mockups (faiths, agents, sermons) is invented and can seed the demo world.
